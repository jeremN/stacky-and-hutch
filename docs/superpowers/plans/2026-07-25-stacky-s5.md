# S5 — Data slice (TanStack Query) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a removable `tanstack-query` brick (new `data` slot) giving SvelteKit and TanStack-Start stacks an equivalent, idiomatic TanStack Query setup, with no wrong-framework dependency leaking.

**Architecture:** T1 restructures the `tanstack-start` brick (`router.tsx` + `__root.tsx`) to carry injection seams so the React integration is additive, and fixes a React hydration bug (`@vitejs/plugin-react`). T2 adds the `tanstack-query` brick: Svelte injects `setQueryClientContext` into the existing `app-head` seam; React injects `routerWithQueryClient` wiring into T1's new seams.

**Tech Stack:** `@tanstack/svelte-query` (^6), `@tanstack/react-query` (^5), `@tanstack/react-router-with-query` (^1), `@vitejs/plugin-react` (^4).

## Global Constraints

- **Git:** one short conventional-commit subject line per commit; **never** a `Co-Authored-By` trailer; run hooks normally (no `--no-verify`).
- **Merge gate is byte/golden/census** (`pnpm vitest run` green); runtime smoke is best-effort.
- **Preserve seams:** `app-head`, `app-shell`, `server-init` keep their markers/positions. New react seams (`router-imports`, `router-setup`, `router-context`, `router-wrap`, `root-imports`, `root-context`) are at column 0.
- **Direct-dep discipline:** every imported package is a direct dep of the matching gated `package.json`.
- **Regenerate goldens with `-u` and inspect every diff.** No unexpected golden may drift.
- **Validated facts (do not "simplify" away):** `type RouterContext = object & { … }` is the empty-safe idiom (intersection exempts `no-empty-object-type`); `router-wrap` is a bare `const`+statement (not `let`+reassign — that trips `prefer-const`); `@vitejs/plugin-react` must be `^4` (v6 needs Vite 7).
